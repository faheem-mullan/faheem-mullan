  <!-- Engineering Practices -->
  <h3>🛡️ ENGINEERING PRACTICES</h3>

  <ul>
    <li>
      <b>SQL Injection Prevention:</b>
      Parameterized PostgreSQL queries using input bindings such as
      <code>$1</code> and <code>$2</code>.
    </li>

    <li>
      <b>Database Integrity:</b>
      Schema-level constraints such as
      <code>UNIQUE</code> and <code>CHECK</code>, with explicit PostgreSQL
      constraint error handling.
    </li>

    <li>
      <b>Password Security:</b>
      Asynchronous <code>bcrypt</code> hashing with no plaintext password
      persistence.
    </li>

    <li>
      <b>Modular Architecture:</b>
      Separation of routing, business logic, and data-access responsibilities.
    </li>
  </ul>
